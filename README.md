📦 CatalogX – Product Catalog App

A responsive product catalog web application built with React and Vite.
Users can browse items by category, filter them dynamically, and view detailed specifications for each product.

🚀 Features
📂 Category-based filtering
🔍 Dynamic grouping of items
📄 Detailed product view with specifications
⚡ Fast performance using Vite
🧭 Client-side routing with React Router
🎨 Clean and modern UI
🛠️ Tech Stack
React.js
Vite
React Router DOM
CSS (custom styling)
